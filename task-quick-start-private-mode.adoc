= 私密模式下 NetApp Console 入门工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以在本地或安全的云环境中安装 NetApp Console。专用模式通常用于没有互联网连接的本地环境以及安全的云区域，包括 https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^]、 https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^]和 https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"] link:task-prepare-private-mode.html["准备部署"]
[role="quick-margin-list"]
. 准备一个满足 CPU、RAM、磁盘空间、容器编排工具等要求的专用 Linux 主机。
. 设置可访问目标网络的网络。
. 对于云部署，请在云提供商中设置权限，以便在安装此软件后将这些权限与 Console 代理关联。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"] link:task-install-private-mode.html["部署控制台代理"]
[role="quick-margin-list"]
. 在自己的 Linux 主机上安装 Console 代理。
. 通过打开 Web 浏览器并输入 Linux 主机的 IP 地址来设置 NetApp Console。
. 对于云部署，请向 NetApp Console 提供之前设置的权限。




[[supported-features-and-services-for-netapp-console-in-private-mode]]
== 私有模式下 NetApp Console 支持的功能和服务

下表列出了在专用模式下安装 NetApp Console 时可用的存储管理功能、数据服务和管理功能。当您将 NetApp Console 安装在云端而不是您的场所时，功能会有所不同。



[[private-mode-installed-in-the-cloud]]
=== 云中已安装专用模式

[cols="3*"]
|===
| 产品领域 | NetApp 服务或功能 | 需要 Console 代理 


.2+| *存储系统管理* 表中的这一部分列出了从 NetApp Console 管理存储系统的支持。它没有指明 NetApp Backup and Recovery 支持的备份目标。 | Cloud Volumes ONTAP | 是的，但由于没有互联网接入，以下功能不可用：自动软件升级和 AutoSupport。 


 a| 
本地ONTAP集群

* 需要从云（安装了 Console 代理的地方）到本地环境的连接。
+
要发现本地 ONTAP 集群，您必须已安装 Console 代理。


| 您可以在没有 Console 代理的情况下使用直接发现，但需要代理才能使用管理功能。 


.3+| *数据服务*  a| 
备份和恢复

* 在私有模式下，NetApp Backup and Recovery 仅支持备份和恢复 ONTAP 卷数据。 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-journey.html#support-for-sites-with-no-internet-connectivity["查看ONTAP数据支持的备份目标列表"^]不支持应用程序数据和虚拟机数据的备份和还原。
* 不支持 Google Cloud 或 https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^]、 https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^]或 https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]

| 是 


 a| 
NetApp 分类

* 唯一受支持的数据源是您可以在本地发现的数据源。 https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#supported-data-sources["查看可在本地发现的源"^]
* 需要出站 Internet 访问的功能不受支持。 https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#limitations["查看功能限制"^]

| 是 


| NetApp Replication | 是* （如果从 ONTAP 本地复制到 ONTAP 本地则不需要） 


| *NetApp 支持合同功能* | 无 | -- 


.6+| *管理功能* | 审核 | 否 


 a| 
Licenses and subscriptions 管理

* 私密模式仅支持 BYOL。
+
对于 Cloud Volumes ONTAP BYOL，仅支持基于节点的许可。不支持基于容量的许可。由于出站 Internet 连接不可用，因此需要在 Console 中手动上载 Cloud Volumes ONTAP 许可文件。



https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-manage-node-licenses.html#add-unassigned-licenses["了解如何添加 licenses"^]
| 否 


| 身份和访问管理 | 是 


| 管理云提供商凭证 | 否 


| 只读模式 | 否 


| 通知 | 否
