== 排除失败的控制台代理部署故障

使用部署报告查找阻止 Console 代理部署的原因，然后重试。

仅当选中*验证代理配置*复选框时，控制台才会提供报告。如果部署成功，则没有报告。

.步骤
. 在*代理部署失败*对话框中，选择*下载报告*。
+
控制台下载包含此验证报告的 PDF 文件。

. 查看报告并修复其列出的问题。
. 在对话框中，选择*重新开始*，然后再次完成部署。
+
您必须重新开始整个过程才能重试。
