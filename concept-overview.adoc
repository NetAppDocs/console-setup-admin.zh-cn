= 用于统一存储管理的 NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 可帮助您管理和保护所有云和本地系统的数据。它包括保护您的数据安全和正常工作的工具。

将 Console 用作软件即服务 (SaaS) 应用程序，或将其安装在云或本地环境中（受限或专用模式）。每种模式都支持不同的功能集和安全要求。

Console 与您在环境中部署的 Console 代理一起工作，以跨本地和云环境管理资源和协调流程。



== 选择如何访问 NetApp Console

通过注册 SaaS 应用程序（标准模式）、将其安装在云端（受限模式）或本地（私有模式）开始使用 NetApp Console。某些功能在受限或私有模式下不可用。

link:concept-modes.html["了解有关部署模式的更多信息"] 。



== 使用 Console 代理扩展 Console 功能

控制台代理是轻量级软件组件，可连接到 NetApp Console SaaS 应用程序和基于云的 API，从而实现高级功能和数据服务。

在受限或专用模式下，在云或本地环境中安装 Console 代理以访问 NetApp Console 应用程序。您需要部署其他代理，以支持需要直接连接到 NetApp Console 及其 API 的功能。

link:concept-agents.html["了解有关控制台代理的更多信息"] 。



== 在 NetApp Console 中管理用户访问和权限

控制台提供身份和访问管理 (IAM)，以提高整个数据基础设施的安全性和控制。围绕组织角色和职责组织存储和数据服务，以降低未经授权访问的风险，同时保持运营效率：

* 顶级 _organization_ 使您能够在整个基础架构中授予和撤销对存储系统和项目的访问权限
* _Folders_ 使您能够根据业务职能或合规性要求将存储资源和项目分组在一起
* _Projects_ 使您能够控制哪些团队访问特定的存储系统、卷和数据服务
* _基于角色的访问控制 (RBAC)_ 允许您向不同级别的团队成员授予存储管理权限，因此您可以委派任务，而无需授予太多访问权限


link:concept-identity-and-access-management.html["了解有关NetApp Console中的 IAM 的更多信息"]



== NetApp Console 的安全与合规性

启用单点登录 (SSO) 等安全和合规性功能，以控制对存储和数据服务的访问。具有组织管理员角色的用户可以默认设置只读模式，要求用户请求提升权限以对存储系统进行更改并使用数据服务。您还可以使用 NetApp Console 监控存储管理和用户活动。NetApp Console 已通过 SOC 2 Type 2 认证，NetApp 向客户提供 SOC 2 报告。

https://www.netapp.com/company/trust-center/compliance/soc-2/["查看 NetApp 的 SOC 2 报告"^]



== NetApp Console 功能和支持的存储

NetApp Console 支持跨本地和云环境的广泛存储类型、功能和数据服务。使用 Console 管理存储系统，监控其运行状况和性能，并启用数据服务以保护和优化数据。

=== NetApp Console 中的存储管理和运行状况服务

NetApp Console 通过单一界面提供 NetApp 存储基础架构的统一管理。

在 Console 中，_Systems_ 表示您发现或部署的存储。直接在 Console 中管理存储卷，或打开系统的管理界面以获取更多选项。

image:screenshot-canvas.png["控制台截图，显示了多个系统。选中其中一个选项，即可启用NetApp数据服务，或者选择“进入系统”来管理存储。"]

除了存储管理之外，还可以使用基础架构服务来监控和管理所有环境中的存储基础架构。

运行状况和性能监控:: 查看存储系统运行状况和性能的仪表板，并获取警报，以便在问题导致故障之前解决问题。
Licenses and subscriptions:: 管理和监控您的许可证和订阅。
生命周期规划:: 识别空间不足的集群，并根据需要添加容量或移动数据。
NetApp数字顾问 (Active IQ):: 使用预测分析和主动支持来优化您的数据基础设施。
软件更新:: 自动化评估、规划和完成 ONTAP 升级。
存储警报:: 查看与ONTAP环境中的容量、可用性、性能、保护和安全性相关的问题。
系统页面:: 在一个地方查看所有存储系统，并快速访问其管理界面。直接从"系统"页面拖放以启用数据服务。
可持续性仪表板:: 分析存储系统的可持续性。




=== NetApp Console 中的数据安全和保护服务

使用内置数据服务来保护关键数据并优化存储效率。

NetApp Backup and Recovery:: 备份和还原云和本地数据。需要订阅。
NetApp Copy and Sync:: 在本地和云数据存储之间同步数据。
NetApp Disaster Recovery:: 使用 VMware Cloud on Amazon FSx for ONTAP 作为灾难恢复站点来保护本地 VMware 工作负载。需要订阅。
NetApp Ransomware Resilience:: 检测可能导致勒索软件攻击的异常情况。保护和恢复工作负载。需要订阅。
NetApp Replication:: 在存储系统之间复制数据以支持备份和灾难恢复。
