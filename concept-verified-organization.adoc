= 了解 NetApp Console 中已验证的组织
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
经过验证的组织将您在 NetApp Console 中的组织链接到您的 NetApp 业务账户身份（例如，CMAT ID）。这有助于 Console 在 NetApp 系统中应用一致的组织身份和治理模型。



== 为什么要验证您的组织

验证您的组织可以帮助您：

* 使您的 Console 组织与您的 NetApp 业务账户身份保持一致。
* 提高管理、报告和支持工作流程的一致性。
* 减少团队跨多个 NetApp 服务工作时的歧义。
* 支持依赖于受信任组织身份的治理控制。




== 验证后发生了什么变化

您的组织通过验证后：

* 组织与 NetApp 公司账号标识关联。
* Console 可以将该组织标识视为业务级映射的权威。
* 如果某些组织配置文件更改由源系统管理，则可能会在 Console 中受到限制。




== 在验证之前

在验证您的组织之前，请确认以下内容：

* 您具有组织所需的管理角色。
* 您有验证所需的组织详细信息。
* 如果企业账户映射需要验证，您已与您的 NetApp 客户团队进行了协调。
