= 登录NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
注册NetApp Console后，您可以从基于 Web 的控制台登录，开始管理您的数据和存储基础架构。

注册后，您的 Console 组织管理员必须将您的用户帐户添加到某个组织中，您才能访问任何资源。如果您已登录但未看到任何资源，请联系您的组织管理员。link:task-user-settings.html#contact-admin["请联系您的组织管理员"]。

.步骤
. 导航到 NetApp Console URL。URL 取决于您的组织正在使用的 Console 模式：
+
** **标准模式**：打开 Web 浏览器并转到 https://console.netapp.com["NetApp Console"]
** **受限模式或专用模式**：打开 Web 浏览器并转到安装 Console 代理的 IP 地址。


. 在*登录*页面上，输入与您的登录关联的电子邮件地址。
. 系统会提示您输入凭据，具体取决于与您的登录相关的身份验证方法。
+
** 您现有的NetApp支持站点 (NSS) 凭证
** 使用您的电子邮件地址和密码的NetApp Console帐户
** 联合连接（如果管理员已为您的组织设置了身份联合）
