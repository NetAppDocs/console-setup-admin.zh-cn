= NetApp Console中的NetApp Disaster Recovery角色
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
您可以为用户分配以下角色，以便他们访问控制台内的NetApp Disaster Recovery。灾难恢复角色使您可以灵活地为用户分配特定于他们需要在组织内完成的任务的角色。如何分配角色取决于您自己的业务和存储管理实践。

灾难恢复使用以下角色：

* *灾难恢复管理员*：执行任何操作。
* *Disaster recovery failover admin*：执行故障转移和迁移。
* *Disaster recovery application admin*：创建和修改复制计划；启动测试故障转移。
* *灾难恢复查看器*：仅查看信息。
